# Full-Site Animation Storyboard by Route

## Global

### First visit

- No branded loader
- Canvas and text render immediately
- Hero entrance runs once

### Internal navigation

- Short route transition
- Header maintains continuity
- Scroll restores correctly
- No repeated full hero intro when returning through browser history unless desired and tested

## Home

### Header

- Opacity/Y entrance
- Current route indicator
- Background solidifies after hero threshold

### Hero

- Rear title mask
- Portrait rise/fade
- Foreground title
- Supporting copy
- Scroll label

### Positioning

- Large statement reveals in 2–3 line groups
- Supporting copy appears without dramatic movement

### Visual interlude

- Image strip may move slightly with scroll
- No infinite marquee by default

### Selected work

Per project:

1. Number
2. Image mask
3. Image scale settles
4. Title
5. Metadata
6. Hover cursor on fine pointer

### About teaser

- Media crop reveal
- Heading line reveal
- CTA underline

### Contact

- Strong line reveal
- Email/CTA follows
- Footer remains static

## Work archive

- Page title reveal
- Published count
- Projects reveal one by one
- Hover is quieter than homepage
- No pinned section

## Case study

### Entry

- Theme colour applied before content flash
- Title and project proposition
- Cover image reveal

### Reading

- Section labels appear gently
- Media reveals on entry
- Text remains mostly static
- Optional short scrub sequence for one meaningful interaction demonstration

### Exit

- Next-project image/title transition
- Native link remains functional

## About

- Hero title
- Portrait/process image
- Biography
- Capabilities stagger
- Process line/steps
- Values
- Contact statement

## Contact

- Heading
- Email
- Form fields appear as a group, not one by one
- Success state transitions within stable layout

## Mobile

- Remove pointer motion
- Reduce stagger
- Avoid long masks that leave blank space
- No custom cursor
- No heavy pinned sequences
- Keep all content visible while JavaScript initializes
