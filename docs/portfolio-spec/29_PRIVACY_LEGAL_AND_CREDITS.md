# Privacy, Legal and Credits

## Privacy page

Add a short privacy page when the site uses:

- Analytics
- Contact-form storage
- Cookies
- Embedded third-party media
- Newsletter tools

State:

- What is collected
- Why
- How long it is retained
- Which providers receive it
- How to request deletion

Do not copy a generic legal policy without matching the actual implementation.

## Cookies

Do not add a cookie banner when no nonessential cookies are used.

When nonessential tracking exists, implement consent according to applicable requirements.

## Project confidentiality

For client work:

- Confirm publishing permission
- Remove private admin data
- Blur real patient/tenant/user data
- Do not expose credentials, internal URLs or analytics
- Clearly mark concept redesigns as concepts

## Asset rights

Track:

- Photographer
- Image source
- Font license
- Music license
- Video license
- Icon source
- Mockup license

## Credits

Every case study should accurately credit:

- Client
- Collaborators
- Photography
- Development partners
- External assets

Do not imply sole authorship when others contributed.

## Copyright
