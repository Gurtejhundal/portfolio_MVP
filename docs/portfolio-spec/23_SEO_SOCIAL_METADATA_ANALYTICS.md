# SEO, Social Metadata and Analytics

## Base metadata

- Title template
- Site description
- Canonical base URL
- Open Graph default
- Twitter/X card default
- Favicon and icons
- Theme colour
- Manifest when useful

## Suggested site title

```text
Gurtejbir Singh — Designer & Developer
```

## Suggested description

```text
Portfolio of Gurtejbir Singh, a designer and developer creating distinctive digital products, brand websites and interactive experiences.
```

## Route metadata

### Home

Focus: identity and selected work.

### Work

Focus: case studies and project archive.

### About

Focus: approach, services and capabilities.

### Contact

Focus: project enquiries and collaboration.

### Project routes

Each must include:

- Project title
- Category
- Accurate summary
- Cover/social image
- Canonical URL
- Published status

## Structured data

Use only valid, factual data.

Possible:

- `Person`
- `WebSite`
- `CreativeWork`
- `BreadcrumbList`

Do not add fake ratings, reviews, employers or awards.

## Sitemap

Include only public routes and published projects.

Draft projects must not appear.

## Robots

- Allow public content
- Disallow private preview routes if any
- Do not block CSS/images needed for rendering

## Social images

Create original 1200×630 images.

Home social card:

- Name
- Role
- Portrait fragment
- Minimal palette

Project social card:

- Project title
- Category
- One project visual
- Consistent branding

## Analytics

Analytics is optional.

When added:

- Use privacy-conscious analytics where possible
- Track only useful events
- Do not collect data without purpose

Suggested events:

- Project opened
- Live project link clicked
- Contact initiated
- Email copied
- Resume downloaded

Do not track every scroll pixel or pointer movement.

## Search quality

- Descriptive headings
- Real text, not text baked into images
- Meaningful alt text
- Fast rendering
- Internal links between project, work and about pages
