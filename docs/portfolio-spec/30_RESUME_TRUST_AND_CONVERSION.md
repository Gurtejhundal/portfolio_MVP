# Resume, Trust and Conversion

## Resume

Provide a resume only when it is current and professionally formatted.

Options:

- `/resume.pdf`
- Contact page link
- About page link

Requirements:

- Clear file name
- Updated experience
- Working email
- Accurate skills
- No duplicate outdated version

## Trust signals

Use real evidence:

- Published projects
- Working live links
- Case-study process
- Client role clarity
- Accurate technical implementation
- Real testimonials only with permission
- Performance/accessibility results when measured

Do not add:

- Fake client logos
- Fake “trusted by”
- Fake awards
- Inflated user counts
- Fabricated testimonials

## Conversion paths

Primary path:

```text
Selected work → Case study → Contact
```

Secondary path:

```text
About → Capabilities → Contact
```

Recruiter path:

```text
Work → About → Resume
```

## CTA placement

- Header contact
- End of selected work
- End of about
- End of every case study
- Footer email

Avoid placing a CTA after every small section.

## Availability

Use a structured status:

- Available
- Limited availability
- Not taking projects

Keep the label current.

## Enquiry qualification

The contact page may clarify preferred projects:

- Product interface design
- Brand and marketing websites
- Interactive editorial experiences
- Full-stack web products

Do not reject smaller projects through arrogant copy.
