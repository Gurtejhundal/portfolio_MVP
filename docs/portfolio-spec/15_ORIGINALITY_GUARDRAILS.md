# Originality and Intellectual-Property Guardrails

## Goal

Adapt a design language, not another creator’s finished expression.

## Acceptable inspiration

- Editorial scale
- Image-led project presentation
- Portrait/typography layering as a general technique
- Minimal navigation
- Restrained motion
- Large negative space
- Compact metadata
- Contact as a strong ending

## Must be original

- Portrait
- Project images
- Written copy
- Project titles
- Case-study content
- Colour accent
- Font choice/pairing
- Navigation geometry
- Exact spacing
- Breakpoints
- Motion choreography
- Cursor design
- Footer composition
- About-page statements
- Icons
- Component implementation

## Do not scrape or paste

- Framer production HTML
- Generated class names
- CSS bundles
- JavaScript bundles
- Image URLs
- Font files
- Analytics identifiers
- Metadata copied verbatim

Generated Framer markup is not a clean reusable component library. Copying it creates technical debt and an obvious derivative result.

## Required differentiation

1. Burgundy rather than lime accent
2. Design-and-development positioning
3. Gurtejbir’s black-and-white Sikh portrait
4. Automotive, cultural storytelling, rental management and healthcare work
5. Stronger technical case-study detail
6. Different navigation composition
7. Different project-layout sequence
8. Original about-page language
9. Original motion timings
10. Honest production status

## Final test

Hide the name and ask:

- Does this still look like a direct copy?
- Are the same visual landmarks in the same order?
- Is the navigation immediately identifiable as the reference?
- Are covers framed similarly?
- Does the accent reproduce the same identity?

If yes, redesign before publishing.
