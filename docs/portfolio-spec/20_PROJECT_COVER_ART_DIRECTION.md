# Project Cover Art Direction

## Why this matters

The editorial layout will not rescue weak screenshots. Project covers are the primary proof of quality and must be designed as carefully as the homepage.

## Shared rules

Every cover must:

- Have one dominant focal point
- Work at desktop and mobile crop ratios
- Remain understandable in under two seconds
- Avoid unreadable tiny UI
- Use real project visuals
- Avoid fake metrics and fake award badges
- Avoid generic floating-device mockups repeated across every project
- Export in WebP or AVIF
- Have a defined width, height and alt description

## House of Details

### Visual character

- Dark
- Metallic
- Cinematic
- Precise
- Automotive

### Cover direction

Use:

- Hero vehicle or high-end detailing close-up
- One fragment of the actual interface
- Black/silver treatment
- Restrained steel-blue accent
- Strong directional light

Avoid:

- Stock sports car unrelated to the client
- Excessive smoke
- Gold luxury clichés
- Tiny website screenshot floating in darkness

Suggested aspect ratio:

- Desktop: 16:10
- Mobile alternative: 4:5

## Sadda Punjab

### Visual character

- Documentary
- Poetic
- Cultural
- Warm
- Emotional

### Cover direction

Use:

- One cinematic chapter frame
- Editorial title treatment
- Ivory/wine/earth palette
- Film grain used lightly
- Real or properly licensed cultural imagery

Avoid:

- Tourism-poster clichés
- Random landmark collage
- Religious imagery used decoratively
- Overloading the cover with text

Suggested aspect ratio:

- Desktop: 4:5 or 5:6
- Mobile may use the same crop with a protected focal point

## RenOS

### Visual character

- Systematic
- Product-focused
- Calm
- Operational

### Cover direction

Use:

- Actual dashboard at readable scale
- One supporting mobile state
- Clear hierarchy
- Neutral product canvas
- One short proposition if needed

Avoid:

- Hiding the interface inside dramatic perspective
- Fake financial charts
- Generic house icons
- Decorative 3D buildings

Suggested aspect ratio:

- Desktop: 16:10
- Mobile: 4:3

## Bibi Kaulan Ji Hospital

### Visual character

- Trustworthy
- Calm
- Accessible
- Practical

### Cover direction

Use:

- Desktop hospital homepage or department experience
- Mobile appointment/OPD state
- Clean white or warm-grey surface
- One restrained healthcare accent
- Real hospital identity where permitted

Avoid:

- Generic doctor stock-photo dominance
- Medical emergency imagery
- Too many floating screens
- Tiny appointment forms

Suggested aspect ratio:

- Desktop: 3:2
- Mobile: 4:5

## Export checklist

For every cover:

- Desktop version
- Mobile version when crop differs
- 2× working export
- Optimized web version
- Alt text
- Safe title area
- Focal point recorded in project data if image component supports it
