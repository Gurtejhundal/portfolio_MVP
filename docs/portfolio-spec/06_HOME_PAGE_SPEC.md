# Home Page Specification

## 1. Hero

### Objective

Communicate role, personality and confidence within the first viewport.

### Copy

Recommended title:

```text
Creative Web
Designer & Developer
```

Alternative:

```text
Digital Designer
& Developer
```

Supporting text:

```text
I design and develop distinctive digital products and web experiences.
```

Availability:

```text
Available for selected projects · 2026
```

### Portrait

Asset:

```text
/public/images/gurtejbir-hero.png
```

Requirements:

- Transparent background
- Black-and-white
- Arms crossed
- Full turban visible
- Face unobstructed
- Bottom anchored
- Explicit width and height
- `object-fit: contain`
- No image-card container

### Layering

1. Background canvas
2. Rear headline layer
3. Portrait
4. Controlled foreground word or metadata
5. Navigation and supporting copy

Never place text across the eyes, nose, mouth or central turban folds.

### Desktop composition

- Minimum `100svh`
- Portrait height approximately 78–90svh
- Headline consumes most of viewport width
- Supporting text uses negative space
- Scroll cue near bottom edge
- One dominant CTA maximum

### Mobile composition

- Recompose intentionally
- Use two or three controlled title lines
- Keep portrait large but not clipped
- Preserve full turban and face
- Put supporting copy in normal flow when absolute positioning becomes fragile
- No horizontal overflow

## 3. Visual interlude or showreel

Do not fake a showreel.

When no credible video exists, build an interactive visual strip containing selected fragments from:

- House of Details
- Sadda Punjab
- RenOS
- Hospital interface

Label:

```text
Selected fragments
```

When a real reel exists:

- Use poster image
- Do not autoplay with sound
- Include controls
- Respect reduced motion
- Defer heavy video on mobile

## 4. Selected Work

Heading:

```text
Selected Work
```

Supporting copy:

```text
A selection of digital products and experiences developed from strategy to deployment.
```

### Layout rhythm

Project 01 — House of Details:

- Wide landscape
- Left-biased
- Dark cinematic cover
- Metadata offset to right or below

Project 02 — Sadda Punjab:

- Taller/narrower image
- Right-biased
- Warm documentary palette
- Large negative space on left

Project 03 — RenOS:

- Near-full-width product composition
- Interface clearly visible
- Short product proposition

Project 04 — Bibi Kaulan Ji Hospital:

- Layered desktop/mobile composition
- Opposite offset from project 02
- Clean healthcare presentation

Every item contains:

- Number
- Title
- Category
- Services
- Year
- One-sentence summary
- Image
- Arrow/link

No technology badges on the homepage.

### Hover

Desktop:

- Image scale to about 1.02–1.03
- Arrow translates slightly
- Optional circular `View project` follower on media only

Touch:

- No hover dependency
- All information visible
- No custom cursor
