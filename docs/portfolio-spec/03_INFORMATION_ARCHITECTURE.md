# Information Architecture

## Primary navigation

- Home
- Work
- About
- Contact

## Secondary actions

- Quick info
- Email
- LinkedIn
- GitHub
- Resume only when current
- Availability status

## `/`

Purpose: Establish identity quickly and route visitors toward strong work.

Sections:

1. Header
2. Editorial hero
3. Positioning statement
4. Visual interlude/showreel
5. Selected work
6. About teaser
7. Contact invitation
8. Footer

## `/work`

Purpose: Show all publishable work without diluting the homepage.

Sections:

1. Work archive heading
2. Published-project count
3. Editorial project stream
4. Optional experiments archive
5. Contact invitation
6. Footer

## `/work/[slug]`

Purpose: Explain decisions, implementation and outcome.

Sections:

1. Project hero
2. Metadata
3. Context
4. Problem
5. Strategy
6. Design direction
7. Experience/interface
8. Development
9. Outcome/status
10. Credits
11. Next project

## `/about`

Purpose: Build trust and explain how Gurtejbir works.

Sections:

1. Large statement
2. Portrait/media composition
3. Biography
4. Capabilities
5. Process
6. Values
7. Tools
8. Contact invitation

## `/contact`

Purpose: Stable, accessible contact destination.

Include:

- Contact statement
- Email
- Social links
- Availability
- Typical project types
- Response expectation only when accurate

## Visitor journeys

Potential client:

Home → Selected project → Case study → About → Contact

Recruiter:

Home → Work → Case study → About → Resume/contact

Peer:

Home → Work → Technical case-study detail → Social link

## Content priority

1. Work quality
2. Clear role
3. Evidence of process
4. Development capability
5. Contact path
6. Tools/background

Do not put a long skills list before the work.
