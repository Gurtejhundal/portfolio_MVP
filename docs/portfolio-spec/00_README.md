# Gurtejbir Singh — Editorial Portfolio Build Pack

This pack defines a complete minimalist portfolio inspired by the **editorial structure, oversized typography, portrait layering, restrained navigation, image-led work presentation, and controlled motion** seen in Karolina Hess’s portfolio.

It is not a request to copy her source code, photographs, project assets, written copy, exact typography, exact navigation geometry, or exact spacing. The final implementation must be recognizably Gurtejbir Singh’s identity.

## Intended stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Motion for React
- GSAP + ScrollTrigger only when advanced scroll choreography justifies it
- `next/image`
- Typed local content first; CMS can be added later

2. Add one art-directed cover image for every featured project.
3. Give the coding agent `01_MASTER_BUILD_PROMPT.md`.
4. Keep the remaining specifications in the repository under `/docs/portfolio-spec/`.
5. Require the agent to read all referenced files before coding.
6. Do not accept desktop-only verification.
7. Do not publish until every item in `13_QA_ACCEPTANCE_CHECKLIST.md` passes.

The imagery will determine most of the perceived quality. Raw screenshots with weak crops will make an otherwise sophisticated layout look amateur.
