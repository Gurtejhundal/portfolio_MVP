# Global Shell, Navigation and Contact

## Site header

Desktop structure:

- Upper-left: `Gurtejbir Singh`
- Upper-right: Work, About, Contact
- Optional edge control: Quick info
- Current route indicated through accent, underline or weight

The header may begin transparent over the hero and gain a canvas background after scroll.

Do not build a generic large SaaS navbar.

## Navigation behaviour

- Persistent across routes
- `aria-current="page"` on active route
- Accessible real links
- Predictable scrolling behaviour
- No hidden navigation on mobile without a clear trigger

## Mobile navigation

- Compact top bar
- Trigger with visible or accessible label
- Large menu sheet or full-screen menu
- Focus trap
- Escape-to-close
- Restore focus to trigger
- Lock page scroll only while open
- Keep email/contact visible

## Quick info panel

Purpose: Provide factual context without bloating the hero.

Suggested content:

- Based in Punjab, India
- Designer and developer
- Available for selected freelance work
- Current focus: product interfaces and immersive web experiences
- Email
- Local time only if implemented accurately

Do not expose a private address or phone number by default.

## Contact panel

Desktop:

- Large editorial statement
- Portrait fragment or project image
- Email as primary action
- Social links
- Copyright/year

Mobile:

- Fully scrollable
- Clear close button
- Selectable email
- No clipped content
- No motion dependency

Suggested statement:

```text
Have a product, brand or idea that needs a stronger digital experience?
```

Primary action:

```text
Start a conversation
```

The `/contact` route must contain the same essential information.

## Footer

Minimal content:

- Name
- Email
- LinkedIn
- GitHub
- Year
- Back to top

Avoid dense sitemap columns until the site actually needs them.
