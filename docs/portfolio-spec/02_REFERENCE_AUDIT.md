# Reference Audit — What to Learn, Not Copy

## Public structure observed

The reference uses a compact shell containing Home, Works, About, Quick info, Contact and a copyright/year marker.

The home page exposes:

- Oversized role statement
- Portrait-led hero
- Short specialization line
- Designer/developer positioning
- Manifesto-style statement
- Showreel prompt
- Recent-work imagery
- Contact invitation

The work archive exposes:

- Selected-work heading and count
- Large project images
- Project names
- Minimal category metadata

The about page exposes:

- Large personal statement
- Experience statement
- Biography and positioning
- Services
- Approach
- Values
- Contact invitation

## Principles worth adapting

### Typography acts as architecture

The display type creates geometry rather than sitting inside a conventional content box.

Adaptation:

- Use Gurtejbir’s role as a spatial layer.
- Let portrait and title overlap.
- Keep supporting copy compact.
- Use deliberate manual line breaks.

### Portrait as a design object

Adaptation:

- Use the supplied transparent black-and-white PNG.
- Anchor it to the viewport bottom.
- Place a title layer behind and one controlled layer in front.
- Keep the face and turban unobstructed.

### Project imagery carries persuasion

Adaptation:

- Create bespoke covers.
- Use controlled changes in size and alignment.
- Keep title/category/year permanently visible.
- Put detail in the case study.

### Navigation is subordinate

Adaptation:

- Keep it compact.
- Avoid a large SaaS navbar.
- Preserve keyboard and mobile usability.

### Contact is a destination

Adaptation:

- Use a strong contact invitation.
- Add an overlay only if a full `/contact` route remains accessible.

## Must not be copied

- Original photography
- Project imagery
- Written copy
- Exact type pairing
- Lime accent
- Exact navigation pill or location
- Exact project dimensions and order
- Exact animation choreography
- Framer-generated production markup
- Internal class names

## Evidence limitation

Public HTML reveals content and image order but not every internal timing value, hover state or breakpoint. Motion values in this pack are original implementation decisions, not claims about the reference source.
